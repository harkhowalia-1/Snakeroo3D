## ✨ Features

| | |
|---|---|
| 🐍 **Smooth 3D snakes** | One continuous tube body with spotted skins in green, red or blue |
| 🍎 **Fruit & power-ups** | Apples, cherries, pears, a dizzy mushroom, plus Snail, Flash, Diet, Twister, Arrow and Serum |
| 🪨 **Crushable obstacles** | Encircle rocks and crates to smash them and grab the loot |
| 🎥 **Three cameras** | Classic overhead, 3D chaser and first person, with a mini-map |
| 🚪 **Adventure mode** | Grow to the target, the gate opens, escape before the timer runs out |
| 🤖 **CPU rival** | Optional AI snake to race for food |
| 🎵 **Chiptune audio** | Original music and retro buzzer sound effects |
| 🌳 **Living arena** | Meadow floor, stone walls and a forest of trees, bushes and flowers |

Every model, texture, sound and the music are generated in code. There are no bundled asset files.

## 🎮 Controls

| | Mac / iPad keyboard | iPhone / iPad touch |
|---|---|---|
| Steer | Arrow keys / WASD | Swipe (tap left/right in 3D views) |
| Speed up | Hold Shift or your current direction | Hold ⚡ |
| Pause | Space / P / Esc | Pause button |

## 📦 Install

- **Mac:** open the DMG and drag the app to Applications. It's unsigned, so right-click → **Open** the first time.
- **iPhone / iPad:** the IPA is unsigned. Sign it with AltStore or Sideloadly, or build from source with your Apple ID.

## 🛠 Build from source

```bash
brew install xcodegen
xcodegen generate
open Serpent3D.xcodeproj
```
