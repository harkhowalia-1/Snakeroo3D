# Snakeroo 3D

A 3D snake game for macOS, iOS and iPadOS (SwiftUI + SceneKit). All art and audio are generated in code.

[Website](https://harkhowalia-1.github.io/Snakeroo3D/) · [Downloads](https://github.com/harkhowalia-1/Snakeroo3D/releases/latest)

Build: `xcodegen generate`, then open `Serpent3D.xcodeproj`.
